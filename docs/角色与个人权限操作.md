# 角色与个人权限操作

本说明对应本次角色管理补齐代码；合并和部署状态由发布记录确认。

## 给一个账号分配财务与 PR 主管

1. 管理员进入「系统管理 → 用户管理」。
2. 新账号选「新建用户」，已有账号选所在行的「修改角色」。
3. 在角色栏同时选择「财务」「PR 主管」。保存的完整选择会替换原角色列表，仍需要的其他角色应一并保留。
4. 目标账号重新登录后使用新角色。修改本人角色会退出当前会话。

同一账号的角色权限合并生效，个人授予和拒绝保留。双角色仍遵守禁止自审等业务规则，也不会自动获得老板终审或管理员身份。

角色编辑入口依据后端实际的角色分配权限显示。新建带角色账号同时要求用户创建和角色分配权限，不能通过新建账号绕过角色分配限制。

## 个人授予、拒绝与恢复默认

「个人权限」用于逐账号调整；不是新增可复用的自定义角色模板。

- 授予：在原角色基础上增加指定权限。
- 拒绝：优先于角色和个人授予，包括角色的整组授权及管理员通配。功能权限和字段权限使用相同优先级。
- 恢复角色默认：删除这一项个人覆盖，不修改角色本身。
- 设置持续生效，不会自动到期。临时交接完成后人工恢复。

例如角色允许全部推广操作，单独拒绝某个推广写权限后，该项操作会被拒绝，其余已授权操作不受影响。字段拒绝也不能由管理员通配绕过。

修改后端已注册权限目录中的个人设置会即时作用于后续请求；页面按钮可能在刷新后更新，后端始终校验权限。
